# CS Game

Counter-Strike 1.6 uslubidan ilhomlangan, Windows uchun yaratilayotgan 3D otishma o‘yini. Xarita keyin foydalanuvchi yuboradigan joy suratlari asosida quriladi.

## Hozirgi holat

Bu boshlang‘ich prototip Godot 4 loyihasi bo‘lib, hozircha oddiy sinov maydoni, birinchi shaxs kamerasi va yurish boshqaruvini o‘z ichiga oladi. Yakuniy xarita, qurollar, botlar va raund tizimi keyingi bosqichlarda qo‘shiladi.

## Ishga tushirish

1. Godot 4 ni o‘rnating.
2. Repository’ni kompyuteringizga yuklab oling.
3. Godot’da `project.godot` faylini oching.
4. **F6** ni bosib joriy sahnani ishga tushiring.

## Boshqaruv

- **W A S D** — yurish
- **Sichqoncha** — qarash
- **Space** — sakrash
- **Esc** — sichqonchani bo‘shatish, chap tugma bilan qayta ushlash
